# Search visibility

Canonical public domain: https://www.wilsonchieu.com. Search helpers live in `lib/seo.ts`; sitemap and robots routes are generated by Next.js. Galleries and image URLs come from the public R2 manifests and refresh with the existing revalidation flow. Do not add fake last-modified dates, testimonials, ratings, prices, venues, or service areas.

## After deploying

1. Verify `wilsonchieu.com` as a Domain property in Google Search Console using its DNS TXT record. Alternatively use the URL-prefix property and set `GOOGLE_SITE_VERIFICATION` to the provided HTML verification content value in Vercel, then redeploy.
2. Submit `https://www.wilsonchieu.com/sitemap.xml` in Search Console. Inspect the homepage and category URLs and request indexing.
3. Confirm Vercel redirects the apex domain to `www` and that the public deployment has `SITE_MODE=public`. Keep the separate admin project set to `SITE_MODE=admin`.
4. Create or claim an eligible Google Business Profile with accurate service areas and photography category. A service-area business should not expose a private home address as a storefront. Keep the name and website consistent with Instagram and real client references.
5. Confirmed service areas are Kuala Lumpur and Seremban. Keep these consistent in `lib/seo.ts`, visible About/FAQ copy and category descriptions. Wilson's full public name and any studio address are not confirmed; do not invent them. Do not create repetitive city pages without distinct useful content.
6. Review Search Console indexing, search queries, clicks and image-search performance after Google has recrawled. Use Google's Rich Results Test for breadcrumb markup and Schema.org's validator for the entity graph. FAQ markup is a semantic description of the on-page questions, not a promise of a Google FAQ rich result.

## AI / answer search

The server-rendered identity, service information, FAQ answers and linked galleries give search tools factual text to cite. Public pages are crawlable under the wildcard robots rule; hosting or CDN bot protection can still block crawlers and should be checked separately. No ranking or citation is guaranteed, and `llms.txt` is not required for Google's AI features. Keep answers factual and publish real shoot descriptions (locations, dates and context only when confirmed).

References: [Google AI search guidance](https://developers.google.com/search/docs/appearance/ai-features), [business details](https://developers.google.com/search/docs/appearance/establish-business-details), [structured-data policies](https://developers.google.com/search/docs/appearance/structured-data/sd-policies).
